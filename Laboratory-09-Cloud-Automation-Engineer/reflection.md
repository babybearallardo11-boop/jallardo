# MISSION REFLECTION
## Mission 9 – The Cloud Automation Engineer

Throughout this laboratory, I learned how automation can make cloud administration easier, faster, and more reliable. Managing hundreds of cloud servers manually would take a lot of time and could lead to mistakes, especially when performing repetitive tasks. Automation helps administrators complete these tasks consistently without having to execute every command themselves.

However, I also realized that automation can be dangerous when scripts contain errors. For example, a destructive command with a typo could affect important files across many servers if it is scheduled or deployed without proper testing. This is why scripts should always be reviewed and tested before being used in an actual production environment.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Docker Compose uses YAML to define services, containers, and their configurations, while Bash scripting allows me to write commands that perform tasks step by step. Both are useful, but they serve different purposes in cloud computing.

Looking back at my activities from Laboratory 1 to Laboratory 9, my understanding of cloud computing has improved. At first, I was only learning basic Linux commands and understanding how cloud environments work. As I continued, I gained experience with infrastructure, containers, storage, deployment, operations, security, and now automation. Each laboratory helped me become more familiar with the tools used by cloud professionals.

Among the roles I experienced, I enjoyed being a Cloud Automation Engineer because I learned how to make repetitive tasks easier through scripting. I may not understand everything immediately, but I learned that patience and practice can help me improve. Completing these activities showed me that I can gradually develop my skills and become more confident in working with cloud technologies.

Overall, this laboratory taught me that automation is an important part of modern cloud computing. It saves time, reduces repetitive work, and helps administrators manage systems more efficiently.
