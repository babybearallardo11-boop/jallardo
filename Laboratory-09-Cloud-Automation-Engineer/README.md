### Mission Overview

This laboratory focuses on the importance of automation in cloud computing and server administration. Instead of performing repetitive tasks manually, I learned how to use Bash scripting and Cron jobs to automate important operations.

For this mission, I created a sample application directory, developed a Bash backup script, made the script executable, and prepared a scheduled task that runs every night at 2:00 AM.

### Mission Objectives

- Understand the basic structure and syntax of Bash scripts.
- Learn how to use variables in shell scripting.
- Create an automated backup script.
- Modify file permissions using the `chmod` command.
- Compress application data using TAR and GZIP.
- Understand and configure Linux Cron jobs.
- Document the automation process using Markdown.

### Commands Executed

| Command | Description |
|---|---|
| `mkdir` | Creates directories |
| `echo` | Creates or displays text |
| `nano` | Opens the text editor |
| `chmod +x` | Makes a script executable |
| `./backup.sh` | Executes the backup script |
| `tar -czf` | Creates a compressed archive |
| `ls -l` | Displays file information |
| `crontab -l` | Displays scheduled Cron jobs |
| `crontab -e` | Edits the Cron schedule |
| `date` | Gets the current date and time |
