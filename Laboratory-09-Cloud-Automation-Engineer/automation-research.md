## Mission 9 – The Cloud Automation Engineer

### 1. Bash Script

A Bash script is a file that contains a collection of Linux commands that can be executed together to perform specific tasks. The `#!/bin/bash` line, also called the shebang, tells the operating system to use the Bash shell when executing the script. It allows users to automate multiple commands instead of entering them individually.

### 2. Variables

Variables are used to store information such as directory paths, filenames, and other values needed by a program. For example, `$BACKUP_DIR` can store the location where backup files should be saved. Using variables makes scripts easier to read, update, and maintain because the same information does not need to be typed repeatedly.

### 3. Cron Job

A Cron job is a Linux feature that allows commands or scripts to run automatically according to a scheduled time. It is useful in cloud operations because administrators can automate repetitive activities such as backups, maintenance, and system monitoring. This helps save time and reduces the chance of forgetting important tasks.

### Conclusion

Through this research, I learned that Bash scripts and Cron jobs are important tools for automating Linux operations. They help administrators manage repetitive activities more efficiently and maintain consistency when working with cloud servers.
