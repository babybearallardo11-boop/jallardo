# Laboratory 03 - Mission Reflection

## 1. Which cloud platform impressed you the most?
Google Cloud Platform (GCP) impressed me the most because of its clean design and unmatched capabilities in big data and containerized workloads. Seeing how Google Kubernetes Engine (GKE) operates alongside tools like BigQuery shows how optimized GCP is for modern, data-driven applications.

## 2. What similarities exist among AWS, Azure, and GCP?
All three cloud providers share identical core architectural principles despite using different product names. Each provider organizes infrastructure into global Regions and isolated Availability Zones, delivers core services in Compute, Storage, Networking, and IAM, and uses web-based management consoles backed by pay-as-you-go pricing models.

## 3. How do business requirements influence cloud platform selection?
Business requirements dictate cloud choices based on budget constraints, existing software investments, compliance rules, and operational expertise. For instance, an organization heavily reliant on Microsoft licenses benefits from Azure, while a company focusing strictly on machine learning research benefits more from GCP's infrastructure.

## 4. What did you learn from acting as a Cloud Solutions Consultant?
Acting as a Cloud Solutions Consultant taught me that cloud architecture is driven by objective problem-solving rather than brand preference. A cloud engineer must analyze business constraints, integration needs, and long-term costs to recommend the platform that best fits the client's specific operational goals.

## 5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?
My GitHub portfolio has transformed from a basic activity repository into a structured technical portfolio. It now demonstrates practical knowledge of multi-cloud architectures, comparative service analysis, strategic decision-making, and professional Markdown documentation standards.
