
# Checkpoint 7 – Mission Reflection

### 1. Which cloud infrastructure component do you think is the most important? Why?

For me, the **network** is the most important cloud infrastructure component because it connects users, servers, applications, and other resources. Even if a cloud server has enough processing power and storage, it would not be very useful if users could not connect to it. A reliable network allows information to move between different parts of the cloud environment.

### 2. How does Linux support cloud computing?

Linux supports cloud computing by giving cloud servers a lightweight and manageable operating system. During the laboratory, I was able to use the terminal to directly inspect the server instead of relying on a graphical interface. Commands like `df`, `free`, `hostname`, and `ip addr` allowed me to quickly check different parts of the system. This showed me why Linux is useful for managing servers.

### 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it gives a clear picture of what will be deployed. It records details such as resources, configurations, network information, and system requirements. Having this information beforehand can reduce confusion and mistakes. If something goes wrong, the documentation can also help identify what was configured and where the problem might be.

### 4. What new skills did you learn during this laboratory activity?

One of the main skills I learned was how to investigate a Linux cloud server using terminal commands. I learned how to identify hardware and system information, check available storage and RAM, inspect mounted file systems, and find network addresses. I also improved my ability to understand command outputs instead of simply running commands without knowing what the results mean.

### 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more useful because it now contains actual evidence of my cloud computing practice. Instead of only showing code, it can also show my experience with Linux, cloud infrastructure, documentation, and system investigation. This mission helped make my portfolio a better record of the technical skills I am developing as an IT student.
