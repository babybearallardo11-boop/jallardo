# Mission Reflection
## Mission 08 – The Cloud Security Engineer

This laboratory helped me understand that securing a cloud server is just as important as deploying and managing it. I learned that a host-based firewall provides an additional layer of protection by controlling incoming and outgoing network traffic, even if the network perimeter is compromised.

Managing open network ports is also important because unnecessary ports can become entry points for attackers. For example, leaving MySQL port 3306 publicly accessible can expose sensitive database information to unauthorized users. This is why only trusted connections should be allowed.

Throughout this activity, I also realized that configuring a firewall requires careful attention. Allowing SSH before enabling UFW is important to avoid losing remote access to the server. It taught me that even a small mistake in security configuration can cause problems.

Looking at my GitHub portfolio with eight completed missions makes me appreciate how much I have learned throughout this subject. Some activities were challenging, but each one helped me become more familiar with cloud computing and Linux commands. Overall, this mission taught me to be more careful and responsible when managing servers because security should always be a priority.
