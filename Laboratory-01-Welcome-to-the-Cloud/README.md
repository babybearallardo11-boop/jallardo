# Laboratory 1 – Welcome to the Cloud

## Mission Overview

This laboratory introduced the Linux environment using **KillerCoda** and **GitHub**. The activities focused on learning basic Linux commands, exploring the Ubuntu environment, managing files and folders, and creating a GitHub portfolio.

## Objectives

* Access a cloud-based Linux environment
* Explore and navigate the Linux environment
* Use basic Linux commands
* Gather system information
* Create and manage files and folders
* Create and organize Markdown files
* Build a GitHub portfolio

## Activities Performed

During this laboratory, I:

1. Created and configured a Linux user.
2. Explored the Ubuntu Linux environment using KillerCoda.
3. Collected system information using Linux commands.
4. Created Markdown files using the `nano` text editor.
5. Created and organized folders and files.
6. Prepared and managed files for a GitHub repository.

## Linux Commands Used

| Command          | Purpose                                        |
| ---------------- | ---------------------------------------------- |
| `whoami`         | Displays the current Linux user                |
| `pwd`            | Displays the current working directory         |
| `hostname`       | Displays the system hostname                   |
| `lsb_release -a` | Displays Ubuntu/Linux distribution information |
| `uname -r`       | Displays the Linux kernel version              |
| `lscpu`          | Displays CPU information                       |
| `free -h`        | Displays memory and RAM information            |
| `df -h`          | Displays disk space usage                      |
| `mkdir`          | Creates a new directory                        |
| `nano`           | Creates or edits text files                    |
| `cat`            | Displays the contents of a file                |

## Skills Learned

Through this laboratory, I learned the fundamentals of:

* 🐧 Linux command-line operations
* 📁 File and directory management
* 📝 Markdown formatting
* 💻 System information gathering
* ☁️ Cloud-based Linux environments
* 🐙 GitHub repository management

## Conclusion

Laboratory 1 provided an introduction to working with Linux in a cloud-based environment. It helped develop basic command-line skills, file management skills, and an understanding of how GitHub can be used to organize and showcase laboratory activities and projects.
