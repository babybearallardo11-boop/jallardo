# Checkpoint 6 – Mission Reflection

Through this laboratory activity, I learned why object storage is a better choice for managing millions of photos compared to traditional block storage. Object storage is designed to handle large amounts of unstructured data by storing files as individual objects with unique identifiers and metadata. It is easier to scale as the number of photos increases, making it suitable for cloud storage systems. In contrast, block storage is commonly used for operating systems, databases, and applications that require fast and direct access to data.

Using Docker also made deploying the MinIO storage server easier and more convenient. Instead of manually installing and configuring all the necessary components, I was able to run MinIO inside a container using a single command. Docker allowed me to configure the ports, administrator credentials, and other settings needed to access the storage server. This experience helped me understand how containerization simplifies application deployment and management.

I also learned that a bucket is a container used to organize and store objects in a cloud storage system. It can hold different types of files, such as photos, videos, and documents. Creating a bucket in MinIO helped me understand how files are organized and managed in object storage. Furthermore, I realized that large enterprise companies need reliable methods to protect their data from physical server failures. They can use replication, redundancy, erasure coding, and regular backups to prevent permanent data loss and maintain access to important files.

Lastly, this laboratory helped improve my confidence in navigating the Linux command line. Although some Docker commands and configurations seemed confusing at first, I gradually understood their purposes by practicing and examining each command. I became more comfortable executing commands, configuring services, and documenting the deployment process. Overall, this activity strengthened my understanding of cloud storage and containerization while encouraging me to continue practicing Linux commands and exploring more advanced cloud computing technologies.
