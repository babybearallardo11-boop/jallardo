# Laboratory 06: The Cloud Deployment Engineer

## Mission Overview
Deploy a private cloud storage application using Nextcloud, MariaDB, and Docker Compose.

## Objectives
- Understand two-tier architecture.
- Create a Docker Compose configuration.
- Deploy a multi-container application.
- Access the Nextcloud setup page.
- Document the deployment process.

## Commands Executed
- `docker-compose up -d`
- `docker-compose ps`
- `docker-compose down`

## Skills Learned
- Linux commands
- YAML configuration
- Docker Compose
- Multi-container architecture
- Markdown documentation
- Git and GitHub
